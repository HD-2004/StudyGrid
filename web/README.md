# StudyGrid frontend

Svelte 5 and Vite client for the StudyGrid planning API.

```powershell
npm install
npm run dev
```

The client defaults to `http://127.0.0.1:8000`. Set `VITE_API_BASE_URL` to use
another API origin.

Verification commands:

```powershell
npm run check
npm run build
npm run test:e2e
```
